# Blazor Tabs - Add the Close Tab Button

⛔ DEPRECATED. This example was deprecated.

Starting from v24.2, the [DxTabs](https://docs.devexpress.com/Blazor/DevExpress.Blazor.DxTabs) component implements tab Close buttons. Enable a tab's [AllowClose](https://docs.devexpress.com/Blazor/DevExpress.Blazor.Base.DxTabBase.AllowClose) property to allow users to close the tab and display the Close button in the tab header. 

You can try this functionality in the [Tabs - Drag and Drop](https://demos.devexpress.com/blazor/Tabs#DragAndDrop) demo.

The current repository will not be updated in the future.
